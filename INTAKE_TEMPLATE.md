# Intake Template — fill this in for each new task/project

Copy this block into CLAUDE.md (or a new project-specific file) BEFORE
the first unattended run. Nobody's around at night to answer questions,
so the more specific this is, the better.

1. **Project**: name, repo/path, one-line description
2. **Tech stack**: language, framework, test runner (or "no preference")
3. **Boundaries**: files/folders to never touch
4. **Needs your okay**: any actions that should NOT happen without
   asking first (e.g. deleting files, changing dependencies)
5. **Test command**: exact command, or "no tests yet"
6. **Lint/build required before PR?**: yes/no
7. **Priority categories**: which of 🐛 🧪 🔍 🏗️ ♻️ ⚡ 📚 🔬 matter most
8. **Starting backlog items**: specific tasks, or "let Claude propose"
9. **Run cap**: max tasks / max hours for one overnight run
10. **PR target branch**
